BunnyOS
A modern OS system based on my favourite animal: bunnies!
---
Features:
- Music player: lets you import MP3 files from your device along with cover art with the same name as the mp3 file, it has a animation style inspired by an ipod where if you hover over the cover art, it has a nice effect. The player has functions such as skip forward/backward and the option to shuffle or repeat music.
- Bunny Gallery: Lets you view pre-set images of bunnies and when you click on an image it changes the image on the background to it.
- Mini website: When you open the mini website, it opens the daily dose of bunny site where you can see a new picture of a bunny daily (I did not make that website i just linked it to my OS, the official site is: https://dailybunny.org/ )
- Settings: Lets you change the background gradient of the OS, lets you toggle between light and dark mode, lets you change the font of the build in clock, lets you toggle the top bar on/off
- Draggable windows: Lets you drag open app windows anywhere on the screen
---
Installation:
All you need to do is download the latest version (BunnyOS v3.0) and open it, it will run in any modern browser such as google chrome, firefox etc.
